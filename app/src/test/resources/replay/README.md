# Trip replays: test data

- `porters-lake.json`: the test map. Its streets are from OpenStreetMap,
  © OpenStreetMap contributors, under the Open Database License (ODbL):
  <https://www.openstreetmap.org/copyright>. The stop, the zones and Sample School are made up.
- `morning.trip`: a made-up morning trip on that map, one check per line.

Fake data only: never a real child's route, school, stop or home. How it is used and how to add a
scenario: DESIGN.md §8, Tests. The map is drawn in `docs/ux/TestMap.dc.html` (Artboard 0.3).
